Webtanan WooCommerce Excel Manager 2.1.1
=====================================

معرفی
-----
افزونه جامع مدیریت محصولات، قیمت‌ها و موجودی ووکامرس با پنل یکپارچه «مدیریت ووکامرس»:
1) داشبورد مدیریتی
2) مدیریت Excel محصولات
3) قوانین هوشمند قیمت
4) تغییر درصدی و ویرایش جدولی
5) تاریخچه تغییرات و بازگردانی

قوانین هوشمند قیمت
------------------
- ذخیره، ویرایش، فعال/غیرفعال‌کردن و حذف قوانین
- شرط بر اساس ویژگی سراسری ووکامرس، دسته‌بندی، شناسه محصول یا SKU
- پشتیبانی از محصولات ساده و تمام تنوع‌های محصولات متغیر
- افزایش/کاهش مبلغ ثابت یا درصدی روی قیمت عادی، حراج یا هر دو
- گردکردن نتیجه به 1، 10، 100، 1000 یا 10000
- پیش‌نمایش اجباری و کنترل تغییر هم‌زمان محصول پیش از اجرا
- محدودیت ایمن حداکثر ۱۰٬۰۰۰ محصول/تنوع در هر اجرا

تاریخچه و بازگردانی
-------------------
- ثبت قیمت قبل و بعد برای هر فیلد قیمت
- ثبت شناسه و عنوان عملیات، قانون، کاربر و زمان تغییر
- گروه‌بندی تاریخچه بر اساس هر اجرای قانون، Excel یا ویرایش گروهی
- بازگردانی گروهی یک عملیات
- جلوگیری از بازنویسی قیمت‌هایی که پس از عملیات دوباره تغییر کرده‌اند
- ثبت خود عملیات بازگردانی در تاریخچه

بخش اکسل محصولات
----------------
خروجی واقعی XLSX با ستون‌های زیر:
1) ID
2) شناسه محصول (SKU)
3) عنوان
4) وضعیت محصول
5) قیمت عادی
6) قیمت حراج
7) موجودی
8) دسته‌بندی
9) نوع محصول
10) ID والد
11) مشخصات تنوع

- قیمت حراج کنار قیمت عادی قرار دارد.
- قالب قیمت بدون .00 و بدون علامت اضافی انتهای عدد است.
- SKU به‌صورت متن واقعی ذخیره می‌شود تا صفرهای ابتدایی حذف نشوند.
- خروجی را می‌توان برای همه محصولات یا یک دسته‌بندی مشخص دریافت کرد.
- امکان لحاظ‌کردن زیر‌دسته‌ها و تنوع‌های محصول وجود دارد.
- محصولات متغیر دارای ردیف والد و ردیف مستقل برای تک‌تک تنوع‌ها هستند.
- قیمت و موجودی هر تنوع از ردیف همان تنوع قابل تغییر است.
- دسته‌بندی، نوع محصول، ID والد و ویژگی‌های تنوع برای شناسایی بهتر نمایش داده می‌شوند.

ورود امن XLSX
-------------
1) فایل بارگذاری می‌شود.
2) مرحله تست اجباری است.
3) گزارش مقدار قبلی و جدید نمایش داده می‌شود.
4) فقط پس از تأیید نهایی تغییرات اعمال می‌شوند.
5) اگر محصول بعد از پیش‌نمایش روی سرور تغییر کرده باشد، آن ردیف رد می‌شود.

تیک «موجودی بی‌تأثیر»
---------------------
با فعال‌کردن این گزینه، ستون موجودی به‌طور کامل نادیده گرفته می‌شود؛ حتی اگر فایل قدیمی موجودی متفاوت یا نامعتبر داشته باشد. این گزینه برای کاربرانی است که فایل قبلی خود را نگه می‌دارند و نمی‌خواهند موجودی فعلی سایت بازنویسی شود.

وضعیت محصول
-----------
در فایل اکسل، وضعیت محصول والد را می‌توان به یکی از موارد زیر تغییر داد:
- منتشر شده / publish
- پیش‌نویس / draft
وضعیت تنوع‌ها از ردیف والد مدیریت می‌شود و در ردیف تنوع قابل تغییر نیست.

تغییر درصدی قیمت
----------------
- انتخاب دسته‌بندی
- امکان لحاظ‌کردن زیر‌دسته‌ها
- افزایش یا کاهش درصدی
- انتخاب قیمت عادی، قیمت حراج یا هر دو
- گردکردن به 1، 10، 100، 1000 یا 10000
- محاسبه قیمت تنوع‌های محصولات متغیر
- پیش‌نمایش اجباری و تأیید نهایی
- جلوگیری از ایجاد قیمت حراج بزرگ‌تر یا مساوی قیمت عادی

ویرایش جدولی قیمت
-----------------
- انتخاب دسته‌بندی و دریافت فهرست محصولات
- نمایش محصولات ساده، والد متغیر و تک‌تک تنوع‌ها
- نمایش دسته‌بندی هر محصول و تنوع در جدول
- ویرایش قیمت عادی، قیمت حراج، موجودی و وضعیت والد
- تیک بی‌اثرکردن موجودی
- ذخیره فقط ردیف‌هایی که واقعاً تغییر کرده‌اند
- صفحه‌بندی برای جلوگیری از فرم‌های بسیار سنگین
- کنترل تغییر هم‌زمان محصول توسط کاربر یا افزونه دیگر

امنیت و فنی
-----------
- دسترسی فقط با قابلیت manage_woocommerce
- بررسی مجوز edit_post برای هر محصول
- Nonce برای همه عملیات نوشتن و دریافت فایل
- محدودیت حجم، تعداد ردیف و تعداد تغییرات
- بررسی ساختار واقعی ZIP/XLSX
- جلوگیری از Zip Bomb، DTD/XXE، ماکرو، فرمول، فایل اجرایی، لینک خارجی و شیء جاسازی‌شده
- فایل پیش‌نمایش خصوصی و دارای زمان انقضا
- تطبیق مجدد اطلاعات محصول پیش از اعمال نهایی
- استفاده از CRUD رسمی ووکامرس
- همگام‌سازی قیمت و موجودی محصول متغیر پس از ذخیره تنوع‌ها
- پشتیبانی UTF-8، BOM، اعداد فارسی/عربی، نیم‌فاصله و حروف فارسی/عربی

نیازمندی سرور
-------------
- WordPress 6.4 یا جدیدتر
- WooCommerce 8.0 یا جدیدتر
- PHP 7.4 یا جدیدتر
- PHP ZipArchive (php-zip)
- PHP XMLReader (php-xml)

نصب یا به‌روزرسانی
------------------
1) از سایت نسخه پشتیبان بگیرید.
2) افزونه قبلی را غیرفعال کنید.
3) فایل ZIP نسخه جدید را از افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه نصب کنید.
4) اگر وردپرس گزینه جایگزینی نسخه فعلی را نمایش داد، جایگزینی را تأیید کنید.
5) ابتدا روی محیط آزمایشی یا با چند محصول تست کنید.
