## Usage in Webtanan WooCommerce Excel Manager

From this point, all new admin interface designs should follow these principles:

- Clean WordPress admin experience
- Minimal and consistent navigation
- RTL Persian-first interface
- Clear information hierarchy
- Fewer clicks for common tasks
- Professional dashboard layouts
- Responsive tables and forms
- Accessible colors and contrast
- Proper empty states
- Clear success/error feedback

## Plugin UI Direction

The plugin admin design should follow:

### Dashboard

- Summary cards for important metrics
- Recent price changes
- Import/export activity
- Warnings and actions

### Product Management

- Powerful filters
- Bulk actions
- Preview before applying changes
- Clear selection states

### Pricing Rules

- Visual rule builder
- Human-readable conditions
- Safe confirmation before execution

Example:

Condition:
Product attribute = Size
Value = 60x120

Action:
Increase price by 500,000 IRR

### History

- Timeline style audit records
- Before/after values
- User and timestamp information
- Rollback actions

## Development Rule

Any future UI changes must consider:

1. User workflow speed
2. Persian RTL usability
3. Mobile responsiveness
4. WordPress admin compatibility
5. Accessibility
6. Avoiding unnecessary complexity
