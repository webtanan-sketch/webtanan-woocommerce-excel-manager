مدیریت امن محصولات، قیمت‌ها و موجودی ووکامرس با فایل XLSX، قوانین قیمت و تاریخچه قابل بازگردانی.

== Description ==

Webtanan WooCommerce Excel Manager ابزارهای مدیریت روزمره کاتالوگ ووکامرس را در یک پنل راست‌چین گردآوری می‌کند.

= مدیریت Excel محصولات =

* دریافت فایل XLSX از محصولات، قیمت‌ها، وضعیت، موجودی، دسته‌بندی و تنوع‌ها.
* حفظ SKUهای دارای صفر ابتدایی و پشتیبانی از متن فارسی و UTF-8.
* بررسی فایل و نمایش پیش‌نمایش پیش از اعمال تغییرات.
* انتخاب دسته‌بندی، زیر‌دسته‌ها و ردیف‌های مستقل برای تنوع‌ها.
* نادیده‌گرفتن ستون موجودی هنگام واردکردن فایل.

= مدیریت قیمت =

* ساخت قوانین شرطی بر اساس ویژگی، دسته‌بندی، شناسه محصول یا SKU.
* افزایش یا کاهش مبلغ و درصد برای قیمت عادی، حراج یا هر دو.
* تخفیف گروهی زمان‌دار با پیش‌نمایش و تأیید.
* ویرایش قیمت و موجودی در جدول صفحه‌بندی‌شده.

= تاریخچه =

* ثبت مقدار قبل و بعد، کاربر، زمان و نوع عملیات.
* بازگردانی محافظت‌شده با بررسی تغییرات جدیدتر.

== Installation ==

1. WooCommerce را نصب و فعال کنید.
2. فایل ZIP افزونه را در «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» نصب کنید.
3. افزونه را فعال کنید.
4. در منوی «مدیریت ووکامرس» ابزار موردنیاز را انتخاب کنید.

برای کار با XLSX، روی سرور PHP باید افزونه‌های ZipArchive و XMLReader فعال باشند.

== Frequently Asked Questions ==

= آیا فایل XLSX بدون پیش‌نمایش مستقیماً تغییرات را اعمال می‌کند؟ =

خیر. ابتدا گزارش فایل نمایش داده می‌شود. تغییرات فقط پس از تأیید نهایی ثبت می‌شوند.

= آیا می‌توان خروجی را به یک دسته‌بندی محدود کرد؟ =

بله. هنگام دریافت خروجی دسته‌بندی را انتخاب کنید و در صورت نیاز زیر‌دسته‌ها را نیز لحاظ کنید.

= آیا SKUهای عددی صفر ابتدایی خود را حفظ می‌کنند؟ =

بله. SKU در XLSX به‌صورت متن ذخیره می‌شود.

= چه نسخه‌هایی لازم هستند؟ =

WordPress 6.4 یا جدیدتر، WooCommerce 8.0 یا جدیدتر، PHP 7.4 یا جدیدتر و افزونه‌های PHP ZipArchive و XMLReader لازم هستند.
